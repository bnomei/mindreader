# @bnomei/mindreader

The npm launcher for [Mindreader](https://github.com/bnomei/mindreader), a deterministic,
privacy-first Neo4j memory MCP server.

```bash
npx -y @bnomei/mindreader@0.3.0 --version
```

The launcher downloads the matching checksummed GitHub Release binary on first use and then
reuses its versioned local cache. It supports GNU/glibc Linux and macOS on x64 and arm64, plus
x64 Windows. See the main repository for configuration and MCP examples.
